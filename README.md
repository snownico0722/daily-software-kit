## clash/

机场自带规则经常太粗：Steam 全走代理、不认识的网站也全走代理。这里换成一套更省事的分流：

- AI 网站单独走代理（可指定美国等节点）
- Steam 社区网页走代理，下载和游戏本身直连
- 需要翻墙的域名走主代理
- 其他默认直连
- 浏览器里还是打不开的，用 ZeroOmega 手动强制走代理

### 里面有什么

| 文件 | 干什么用 |
|------|----------|
| `clash全局扩展脚本-v1.1.txt` | 贴进 Clash 客户端的脚本 |
| `clash全局扩展覆写配置示例.txt` | 想自己加/删规则时参考 |
| `clash脚本说明.txt` | 几句设计备注 |
| `ZeroOmegaOptions-v1.bak` | 浏览器插件配置备份，直接导入 |

### 怎么用

**Clash 客户端**（Clash Verge Rev、Mihomo Party 等，名字因软件而异）：

1. 找到配置里的「全局扩展脚本」之类选项
2. 把 `clash全局扩展脚本-v1.1.txt` 全文粘贴进去并保存
3. 更新订阅，在策略组里选好节点就行  
   AI 那一组可以单独选美国等节点

**想自己加规则时**，看 `clash全局扩展覆写配置示例.txt`，按示例写就行。

**浏览器（ZeroOmega）**：

1. 安装 [ZeroOmega](https://github.com/zero-peak/ZeroOmega)
2. 导入 `ZeroOmegaOptions-v1.bak`
3. 端口对一下：
   - **7897**：平时浏览器走的代理
   - **7898**：强制走代理（打不开再切这个）
   - **7899**：强制直连

如果你电脑上的代理端口不是 7897，脚本和 ZeroOmega 两边都要改成实际端口。

### 客户端里会看到的策略组

| 名字 | 用途 |
|------|------|
| 默认代理服务 | 平时翻墙用的主入口 |
| AI定向代理 | AI 相关网站 |
| Cloudflare定向代理 | 浏览器里 Cloudflare 相关流量 |
| Steam社区代理 | Steam 社区页、头像等 |
| 浏览器转发代理 | ZeroOmega「强制代理」对应这一组 |
| 最快节点 | 自动测延迟 |
| 故障转移 | 节点挂了自动换 |
| 未命中流量代理 | 没匹配到规则的流量，默认直连 |
